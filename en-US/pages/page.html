This is the internal page template: same header, grid and typography as the rest of the site.

Template markup: the main text block is width-limited so lines stay readable, while the service elements — breadcrumbs, heading and lede — are assembled from shared classes.

Adding a new page

  • Copy this file and rename it for the new section.
  • Replace the heading, lede and the content inside .prose.
  • Add an item to the navigation lists in the header and footer.
  • Mark the item with aria-current="page".
